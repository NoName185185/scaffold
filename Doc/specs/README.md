Шаблоны:

- [product.md](product.md) — продукт и пользователи
- [architecture.md](architecture.md) — целевая архитектура
- [roadmap.md](roadmap.md) — очередь работ

Новая фича: `specs/<имя>.md` + ссылка из этого файла.
