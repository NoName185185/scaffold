# Роадмап

Источник приоритетов: корневой README «Дальнейшие шаги» + здравый смысл каркаса.

## Сейчас (каркас)

- [x] Docker Compose: db + API + Vite
- [x] Prisma: Board, Post, Comment, Moderator
- [x] CRUD-минимум постов и досок
- [x] Лента одной доски во фронте + голоса

## Следующие итерации

1. **Доски во фронте** — список, переход по slug, форма создания поста
2. **Загрузка изображений** — multer или аналог, раздача `/uploads`
3. **Auth модераторов** — JWT + bcrypt, закрыть `POST /boards` и `DELETE /posts/:id`
4. **Rate limit** постинга
5. **Панель модератора** — удаление, баны по `authorHash`
6. **AI-модерация** — опциональный хук перед публикацией

Каждый пункт при старте работы получает свой файл `specs/<тема>.md`.
