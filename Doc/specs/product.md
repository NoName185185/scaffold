# Продукт: University Board

Полный канон: [Doc/context/README.md](../context/README.md). Ниже — краткая выжимка для спек.

## Проблема

Студентам нужен внутренний борда-форум (доски → треды → комментарии → голоса) с публичной анонимностью и модерацией со стороны университета.

## Пользователи

| Роль | Сейчас в коде | Цель |
| --- | --- | --- |
| Пользователь | Лента `/study/`, голос без аккаунта | Регистрация, пост/комментарий, чекбокс анонимности |
| Moderator | Модель есть, удаление открыто всем | JWT, удаление, баны по `authorId`, жалобы |
| Admin | `role` в схеме, не используется | Доски, роли, в API видит автора анонимных постов |

## Принципы

- Постить можно только авторизованным; для публики автор скрывается, если `isAnonymous`
- В БД всегда `authorId` — для модерации, не для ленты
- Доски по `slug`
- Админ-эндпоинты закрыты по умолчанию

## Вне скоупа MVP

Мобильные приложения, SSO университета, реалтайм-чат.
