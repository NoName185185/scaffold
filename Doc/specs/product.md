# Продукт: University Board

## Проблема

Студентам нужен простой анонимный борда-форум по темам (учёба, быт, объявления) без обязательной регистрации для чтения и постинга.

## Пользователи

| Роль | Сейчас | Цель |
| --- | --- | --- |
| Анонимный читатель | Видит ленту `/study/` | Выбирает доску, читает, голосует |
| Анонимный автор | Только через API | Форма поста/комментария в UI, опционально картинка |
| Модератор | Модель в БД, API удаления открыто всем | Логин, удаление постов, баны по `authorHash` |
| Админ | `role` в схеме | Создание досок, управление модераторами |

## Принципы

- Постинг по умолчанию анонимный; идентификация — хеш, не ФИО
- Доски разделены по `slug`
- Модерация не должна требовать аккаунт у обычных пользователей

## Вне скоупа каркаса (осознанно)

Мобильные приложения, SSO университета, реалтайм-чат — не блокируют MVP веба.
