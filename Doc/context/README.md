# Контекст

Сюда кладём всё, что не код, но нужно, чтобы понять продукт: картинки, примеры, выгрузки, референсы.

## Подпапки

| Путь | Что класть |
| --- | --- |
| `images/` | Скриншоты UI, мокапы, схемы, диаграммы |
| `examples/` | Примеры запросов/ответов API, фикстуры, шаблоны постов |
| `references/` | Выдержки из ТЗ, ссылки на аналоги, заметки с созвонов |

Имена файлов: `YYYY-MM-DD-короткое-имя.ext`, например `2026-09-07-feed-empty.png`.

В markdown ссылайтесь относительно этого каталога:

```md
![Пустой фид](images/2026-09-07-feed-empty.png)
```

```md
См. пример создания доски: [create-board.json](examples/create-board.json)
```
