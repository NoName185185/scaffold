# Обзор реализации

Каркас анонимного университетского борда: доски → посты → комментарии и голоса.

```
браузер (Vue, :5173)
    → HTTP JSON
Express API (:4000/api)
    → Prisma
PostgreSQL (forum)
```

## Что уже есть

- Регистрация / вход / `GET /auth/me` (модель `User`, JWT)
- Список досок и создание доски без авторизации
- Публичная лента постов доски `study` с комментариями
- Создание поста, комментария, upvote/downvote (API; форма поста в UI ещё нет)
- Удаление поста без проверки роли
- Health-check `GET /api/health`
- Docker Compose: `db`, `backend`, `frontend`

## Чего нет

- `authorId` / `isAnonymous` на постах (ещё `authorHash`)
- Загрузка файлов (только поле `imageUrl`)
- Rate limit, AI-модерация, панель модератора
- Выбор доски во фронте: slug захардкожен как `study`
- Форма создания поста в UI
