# Обзор реализации

Каркас анонимного университетского борда: доски → посты → комментарии и голоса.

```
браузер (Vue, :5173)
    → HTTP JSON
Express API (:4000/api)
    → Prisma
PostgreSQL (forum)
```

## Что уже есть

- Список досок и создание доски без авторизации
- Лента постов доски с комментариями
- Создание поста, комментария, upvote/downvote
- Удаление поста без проверки роли
- Health-check `GET /api/health`
- Docker Compose: `db`, `backend`, `frontend`

## Чего нет (и это сознательно в каркасе)

- JWT / сессии / логин модератора (модель `Moderator` в схеме есть)
- Загрузка файлов (только поле `imageUrl`)
- Rate limit
- AI-модерация
- Выбор доски во фронте: slug захардкожен как `study`
- Форма создания поста в UI (API есть, клиент `createPost` экспортирован)
