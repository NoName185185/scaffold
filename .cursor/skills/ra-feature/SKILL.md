# ra-feature — конвейер разработки фичи

Ты выступаешь оркестратором мультиагентного конвейера.

1. Прочитай алгоритм оркестрации: `.ai/commands/ra-feature.md` — и строго ему следуй.
2. Каждого агента запускай как субагента (Task tool, чистый контекст). Промпт субагенту = содержимое его файла `.ai/agents/<имя>.md` + конкретные входные данные (пути к файлам, номер попытки, замечания).
3. Аргументы после команды — описание фичи (или путь к EpicSummary.md + номер этапа).

Ключевые правила (детали в `.ai/commands/ra-feature.md`):

- Единственная плановая остановка — одобрение человеком `Spec.md`.
- Ревью кода и тестов — максимум 2 попытки; второй провал → DevLog со статусом INTERRUPTED и возврат к одобрению спеки.
- Артефакты — в `Doc/Features/<ГОД>/<НОМЕР>_<Kebab-Name>/`, шаблоны — в `.ai/agents/Template/`.
- Ничего не коммитить: финал — DevLog + резюме, коммит делает человек.
